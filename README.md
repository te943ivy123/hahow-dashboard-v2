# Hahow Dashboard V2｜組員可修改版

這一包已經整理成「解壓縮後，組員可以直接開發」的版本。

## 第一次拿到檔案，只做 3 件事

1. **先把 ZIP 完整解壓縮**，不要直接在 ZIP 裡面執行。
2. 電腦需要有 **Python 3.11 或 3.12**。
3. 雙擊 **`第一次使用_點我安裝並啟動.bat`**。

第一次會自動：
- 建立 `.venv` 專案環境
- 安裝 Streamlit / pandas / numpy / plotly
- 啟動網站
- 自動用瀏覽器開啟 Streamlit

之後要開網站，只要雙擊 **`之後開網站_點我.bat`**。

---

## 要改程式時

主要修改：

- `app.py`：Dashboard 網頁程式
- `README.md`：說明文件（需要時才改）

正式分析資料放在：

- `data/`

### 重要：data 裡的正式 CSV 先不要隨便改

Dashboard V2 的數字全部直接讀取正式 CSV。  
如果只是改版面、文字、圖表呈現，**只改 `app.py` 就好**。

目前正式資料口徑：

- 完整市場分析：1,117 筆
- ML 單標籤資料：1,079 筆
- 跨分類資料：38 筆，不混入目前 12 類單標籤模型

## 修改完怎麼看結果？

存檔後回到瀏覽器。Streamlit 通常會提示重新執行；重新整理或 Rerun 就能看到修改。

如果網站已關掉，雙擊：

`之後開網站_點我.bat`

---

## 如果打不開

先雙擊：

`檢查環境.bat`

如果還是不行，把黑色視窗**最後幾行錯誤訊息截圖**傳給組員即可。

### 常見狀況

**顯示找不到 Python**
→ 電腦尚未安裝 Python，或安裝時沒有加入 PATH。

**套件安裝失敗**
→ 先確認網路正常，再重新執行第一次安裝檔。

**顯示缺少正式資料檔**
→ 確認 `data` 資料夾和 `app.py` 在同一層，而且沒有把 CSV 移走。

**瀏覽器沒有自動開**
→ 看黑色視窗是否出現 `Local URL`，通常是 localhost 網址；不要關閉黑色視窗。

## 檔案用途

- `app.py`：Dashboard 主程式
- `data/`：正式 CSV
- `requirements.txt`：需要安裝的 Python 套件
- `第一次使用_點我安裝並啟動.bat`：組員第一次使用
- `之後開網站_點我.bat`：之後每次開網站
- `檢查環境.bat`：打不開時檢查
- `start_dashboard.bat`：備用啟動檔
- `CHANGELOG_V2.md`：原 V2 修改紀錄

## 不用做的事

組員不需要自己輸入 `pip install`，也不需要自己找 Streamlit 指令。  
照上面的 `.bat` 檔操作即可。
